# Git Ingest UI

The Git Ingest UI lets you explore repositories or local directories directly from the workspace.

1. Open the **Git Ingest** section in the Workspace sidebar.
2. Provide a repository URL (or a local path if running locally) and optional parameters like branch or commit.
3. Click **Ingest** to fetch the repository and display a summary, directory tree, and file content.
4. You can toggle whether file contents are loaded.

This feature is useful for quickly browsing a project and sharing code snippets with inline citations.
